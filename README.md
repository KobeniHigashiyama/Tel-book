# Tel-book

Учебный проект телефонной книги на Go.

В `phoneBook.go` реализованы добавление, удаление, поиск по номеру телефона и вывод списка контактов. Данные сохраняются в `csv.data` в каталоге запуска; файл создаётся автоматически. Поиск использует индекс телефонов и обновляет время последнего обращения (`LastAccess`).

```bash
go run phoneBook.go insert Ali Karimov 998-90-123-45-67
go run phoneBook.go search 998901234567
go run phoneBook.go list
go run phoneBook.go delete 998901234567
```

Телефон должен состоять из цифр; дефисы удаляются автоматически. Повторное добавление того же номера запрещено. CSV содержит четыре поля без заголовка: имя, фамилию, телефон и время обращения в секундах Unix.
